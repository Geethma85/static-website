# Codacs - Online Learning Platform 🚀

A modern, clean, and fully responsive static landing page built for **Codacs**, an e-learning platform offering coding courses, certifications, and mentorship tracks.

🔗 **Live Demo:** [https://geethma85.github.io/static-website/](https://geethma85.github.io/static-website/)

---

## 📸 Overview & Features

- **Fluid & Responsive Design:** Optimized across mobile, tablet, and desktop screens using modern CSS Flexbox and Grid layouts.
- **Mobile Navigation Drawer:** Lightweight, vanilla JavaScript mobile menu toggle.
- **Interactive Course Directory:** Grid-based cards showcasing popular languages and frameworks.
- **Dynamic Pricing & Testimonials:** Plan highlights, student reviews, and FAQ accordion styling.
- **Authentication Interfaces:** Modern, split-view Sign In and Sign Up pages.

---

## 🛠️ Built With

- **HTML5:** Semantic structure and accessible markup.
- **CSS3:** Custom styles, CSS variables, CSS Grid, Flexbox, and fluid typography without external frameworks.
- **Vanilla JavaScript:** Minimal DOM manipulation for UI interactivity.
